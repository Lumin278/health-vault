# 用药（索引）

药品说明书库在哪、覆盖什么、边界在哪。**查询命令与输出纪律见 `规范.md`；来源与许可见 `来源与许可.md`。**

## 数据长什么样

一份完整的中文药品说明书库有上万条、每条数千字 —— 塞成 Markdown 既难读也难查。做法：**SQLite + 查询脚本**，只在需要时取命中行（省上下文，也快）。

| 对象 | 默认位置 | 内容 |
|---|---|---|
| 说明书库本体 | `$DRUGDB` → 否则 `~/drugdb/drugs.sqlite` | `drugs` 表：适应症 / 禁忌 / 警告 / 成分 / 用法 / 不良反应 / 相互作用 / 贮存 / 批准文号 / 来源；`interactions` 表：配对 + 风险等级；另有 FTS5 全文索引 |
| 查询脚本 | 本技能 `scripts/drugdb/q.py` | 概况 / 单字段 / 两药相互作用 / 全文搜索 |
| 建库脚本 | 本技能 `scripts/drugdb/build.py` | `--src` 原始 JSON、`--out` 产出库 |

**本技能不附带任何药品数据**（体积 + 许可）。库不在时 `q.py` 会提示先跑 `build.py`。

升级技能后若已有旧说明书库，建议重建一次以启用中文 trigram 索引；不重建也能查询，短词会自动回退到 LIKE。

## 覆盖与局限

- 中文说明书为主（国产剂型居多），常见药基本齐全；**不是全量药典**，冷门药 / 新药可能没有
- **名字是剂型级的**（`布洛芬缓释胶囊`）→ 回答时归一到通用名（`布洛芬`）
- 相互作用只收说明书里**写明**的配对；查不到不等于没有

## 用法边界

- ✅ 能答：这药是干嘛的、常见副作用、说明书写的禁忌、和哪些药有相互作用（**说明书原文照录**）
- ❌ 不答：该不该吃 / 要不要停 / 换什么药 / 这个症状是不是这药引起的 —— 找医生或药师
