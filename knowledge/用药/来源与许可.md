# 用药（来源与许可）

## 本仓库带什么

`scripts/drugdb/` 只有**建库与查询工具**（表结构 + 命令），**不附带任何药品数据**。库由使用者自备：默认位置 `$DRUGDB` → 否则 `~/drugdb/drugs.sqlite`。

## 数据自备的口径

- 用有明确授权、可自行再分发的中文说明书数据源；先确认许可，再按 `scripts/drugdb/build.py` 的表结构（`drugs` / `interactions` / `drugs_fts`）导入。
- 公开可得的中文说明书整理集常见**许可不明**（仓库标为 NOASSERTION 之类）：这类数据只作**本机个人参考**，不入 git、不随技能分发、不推公网仓库。
- 库不在位时 `q.py` 会提示先跑 `build.py`；说明书拿不到 → 只照药盒 / 说明书原文，绝不凭记忆补写适应症。

## 有明确授权的替代来源

| 来源 | 说明 |
|---|---|
| RxNorm / RxNav（美国 NLM） | 授权明确，REST API 免认证，给药名归一与相互作用 |
| OpenFDA 药品标签 | 含 `drug_interactions` / `adverse_reactions`，可批量拉取 |

换来源时按 `scripts/drugdb/build.py` 的表结构导入即可。
