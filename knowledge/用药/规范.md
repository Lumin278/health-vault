# 用药（规范）

用户问「XX 是什么药 / 有什么副作用 / 有什么禁忌 / 和我吃的药冲不冲」时用本文件。数据位置见 `索引.md`。

## 查询命令

```bash
python3 scripts/drugdb/q.py 布洛芬              # 命中概况：剂型清单 + 成分/适应症/禁忌/不良反应/相互作用摘要
python3 scripts/drugdb/q.py --full 布洛芬        # 不截断（只在需要原文时用）
python3 scripts/drugdb/q.py --field 禁忌 布洛芬   # 只看一个字段：适应症|禁忌|不良反应|相互作用|成分|用法|警告|储存|批准文号
python3 scripts/drugdb/q.py -n 阿莫西林           # 只要规范名 + 成分 + 剂型清单
python3 scripts/drugdb/q.py -i 阿司匹林 华法林     # 两药相互作用（查「能不能一起吃」用这条）
python3 scripts/drugdb/q.py -s 头痛 --limit 5     # 全文搜索（名称/成分/适应症/不良反应）
```

Windows 上没有可用的 `python3` 时，改用 `python` 或 `py -3`。

库不在默认位置时加 `--db 〈路径〉`；库不存在时脚本会提示先跑 `build.py`。

## 输出纪律（省 token）

- 默认输出已截断（每条字段 ~420 字）；**不要把库文件读进上下文**，永远走查询脚本
- 只把用户问的那几条报给用户；需要原文时再加 `--full` 或 `--field`
- 库里名字是**剂型级** → 回答时**归一到通用名**
- 相互作用查不到两药直配时，脚本会自动分别列出两药的相关提示 —— 要说明「这不是两药直配记录」

## 药名归一（与归档口径一致）

- 档案里写 `通用名（剂型）`，如 `布洛芬（缓释胶囊）`；剂量用户补充才记，不猜
- 用户报**商品名**（优甲乐 / 芬必得 / 络活喜）：先查库 → 找到对应通用名 → **回问用户确认** → 再落库；查不到就问「药盒上写的名称是什么」
- 新药 / 库中没有的药：告知「库里没有」，请用户拍药盒或读药名，**不要编**

## 硬边界

- ❌ 不答「我该不该吃 / 要不要停 / 换什么药 / 这个症状是不是这药引起的」 → 让用户问医生或药师
- ❌ 不对相互作用做临床判断，只照录说明书原文 + 风险等级 + 来源
- ❌ 不给剂量、不推荐、不排序
- ✅ 每次输出末尾提醒：「以上为说明书原文摘录，用药请遵医嘱/咨询药师」。
