# 知识库（技能自带）

这一层放**可查、可引用的资料性内容**（技能自带的「知识」）。

| 层 | 放什么 | 例 |
|---|---|---|
| 本层 `knowledge/` | 技能自带的知识（人与 agent 都能读的资料） | 用药：索引 / 规范 / 来源与许可 |
| `references/` | 干活的流程与字段口径 | vault-spec、entity-schema、术语表 |
| `templates/` | 页面骨架 | 汇总页、单报告页、两张 CSV 表头 |
| 库内 `8-知识库/` | **数据**（受控词表） | zz-项目名规范.md |
| 库内 `〈成员〉/` | 病历数据 | 报告、指标、用药 |

规矩：同一份内容只有一处出处。**本层写通用版**（不含任何机器路径）；**库内那层写实况版**（本机路径与条数）。查数据先看库内实况，拿不到再按本层口径降级。
