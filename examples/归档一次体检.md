# 例：归档一张化验单（最小完整链路）

输入：会话里发一张化验单照片 + 一句"归档"。

## 1 准入确认（不确定的才问，一次问完）

```
单据类型  化验单          （单据抬头印「检验报告单」）
患者      与库内成员一致   （姓名栏 与成员名一致）
机构/日期 某某市第一医院 / 2026-10-08
项目名    肝功、血常规     （词表命中）
同一次？  单张单据，不触发 7 天合并问题
```

## 2 落笔（5 处）

```
〈成员〉/4-就医记录/就医记录总表.md     +1 行（ID 20261008a）
〈成员〉/2-检查报告/2026-10-08-某某市第一医院-肝功+血常规/
    ├── 2026-10-08-某某市第一医院-肝功+血常规.md   ← 套 templates/检查活动-汇总页模板.md
    ├── 报告/肝功-2026-10-08.md                     ← 套 templates/单报告页模板.md
    ├── 报告/血常规-2026-10-08.md
    └── attachments/2026-10-08_肝功+血常规_原图.jpg  ← 复制上传缓存里的图
〈成员〉/5-指标/指标总表.csv           +N 行（数值型；图像型不进）
〈成员〉/7-视图/化验指标追踪.md         重生成（派生）
```

关键行（报告页，判定列只抄单据）：

```
| 指标名 | 结果 | 单位 | 参考范围 | 判定 |
|---|---|---|---|---|
| ALT(丙氨酸氨基转移酶) | 134 ↑ | U/L | 9-50 | ↑ |
| AST | 45 | U/L | 15-40 |  |
```

（↑ 是单据印的；AST 单据没印标记 → 留空，不用参考范围自己判）

## 3 自检 + 提交 + 回报

```
git add 〈本次路径〉 && git commit -m "归档: 2026-10-08 肝功+血常规"

已归档（commit 1a2b3c4）：就医记录 +1 行 · 报告页 2 个 · 指标 +12 行 · 原图 1 张
改过的文件：…
标了待核对：血常规第 3 项单位被浮层遮挡 [待核对]
原图位置：…
（档案是整理，请与医生确认）
```
