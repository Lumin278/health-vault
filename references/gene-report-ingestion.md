# 基因解读报告（DTC）归档口径

配套 SKILL.md 的「基因解读报告」节。这份文件只在真的要抽基因报告时读。

## 1. 报告体裁（机构版式，决定切块正则）

- 每个项目 **3–4 页一块**：p1 结论 + 依据句 + 商品名清单 / 药物简介；p2 商品名清单续；p3 说明书条文 + 位点表开头；p4 位点表续 + 人群样本 + 检测局限。
- 块首页常是孤立的页码数字（`1`），标题形如 `我的X用药量` → 这是最稳的块边界正则。
- 汇总表页（通常 3 页）列「药名 + 结论」，但**条数可能与正文块数对不上**（实测汇总表条数与正文块数差一倍以上）；以正文块为准，把差额原样报给用户裁决，别静默取一个。
- 一页里约 90% 是说明书条文、商品名清单、药物相互作用长清单 —— **不属于"你的数据"**，整块丢弃；只留结论、依据句、位点表。
- 「人群样本 / 检测局限」是全局通用文本，抄一次进报告说明即可。

## 3. 芯片世代与能力边界

| 世代 | 平台 | 位点 | 备注 |
|---|---|---|---|
| V1（2015–2018） | 赛默飞 / Affymetrix 定制 | 约 60 万（约一半在基因区，覆盖 1.6 万基因） | 早年订单多是这一代 |
| V2 | Illumina（2018 合作之后） | 核心数据 txt 二十几 MB | 与 V1 靠文件体积区分（V1 十几 MB） |
| 3.0 / CGA（2019-12 发布） | GSA v3 骨架 + 中国人群优化 | **684,023 SNPs**；已知临床价值位点 **18%**（ClinVar ≈6 万、PharmGKB ≈4000、GWAS catalog 1.3 万） | 14 万位点为中国人群新增 |

- **芯片升级 ≠ 证据升级**：换芯片提升的是覆盖率与分型质量，不改变研究证据强度。旧样本在 App 里看到的新条目，很多是 **imputation 推算**而非实测 —— 报告变长不等于结论变强。
- 为用药准确而去重测一张芯片通常不值：真要做 CYP2D6 / HLA，医院专项检测更准且直接可用。

## 4. 可测性三档（决定这条结论能信到几成）

| 类型 | 代表位点 / 基因 | 可信度 |
|---|---|---|
| 单 SNV | CYP2C19\*2/\*3/\*17、CYP2C9\*3、VKORC1、SLCO1B1 rs4149056、TPMT\*3C、NUDT15、APOE rs429358+rs7412、ALDH2 | ✅ 可靠 |
| 拷贝数 / 重复序列 / 罕见变异 | **CYP2D6 全部**、UGT1A1\*28（TA 重复）、RYR1 / CACNA1S（恶性高热）、BCHE、线粒体 MT-RNR1 m.1555A>G | ❌ 测不准，只当线索 |
| HLA 分型 | HLA-B\*5801（别嘌醇）、\*15:02（卡马西平/苯妥英）、\*57:01（阿巴卡韦） | ⚠️ tagSNP 代理：阴性可信，阳性须临床分型 |

CYP2D6 出现在十几个药的 FDA 强证据条目上（可待因、曲马多、阿立哌唑、利培酮、美托洛尔、氟卡尼…），而芯片物理上测不出拷贝数 —— 这是"报告看起来最有料、实际最不可用"的典型，务必单独标注。

## 5. 证据来源怎么引

- **FDA《Table of Pharmacogenetic Associations》**：能直接抓、能直接引；Section 1 = 「数据足以支持治疗管理建议」（写明调整剂量 / 避免使用 / 禁忌），最硬的一手。
- CPIC 官网 `/guidelines`、`/genes-drugs` 是 JS 渲染，`web_extract` 抓不到正文 —— 别写成"CPIC 说"，改引 FDA 表或具体指南 PDF。
- 中国人群锚点：HLA-B\*5801 在汉族携带率 6–8%（单中心报道 10.74%），别嘌醇致 SJS/TEN 致死率 10–40%，ACR 指南已点名中国汉族用药前筛查。

## 6. 抽取实测（量级参考：一份两千余页的中文报告）

- 文本层完整：每页数百字、几乎每页都有字 → **不需要 OCR**（别凭体积断定是扫描件）。
- 全量抽文本数秒级；连图片元数据走一遍约一分钟；页级 `jsonl` 落盘后一切查询都靠它。
- 切块：块首页正则 → 百余个条目；逐块抽 结论 / 依据句 / 位点表。
- 字段正则要兜多写法：`项目：HLA-B B*5801` 这种复合行；依据句前缀 `疗效：` / `不良反应：` 二选一；多捕获组先取第一个非 None 再 `.strip()`（否则 `None.strip()` 把整批跑崩）。
- **交付前自查**：同一位点在不同条目下必须给同一基因型（例：同基因相关条目的 rs4149056 必须一致）—— 对不上说明抽错位。
- 抽出来的量级参考：全部条目里**常规用药约占三分之二、非常规约三分之一**（非常规按「警惕疗效不足 / 警惕不良反应 / 建议增加剂量 / 建议减少剂量」四类分列）。**别拿汇总表条数去推总量** —— 汇总表往往只列常规用药，会把非常规条目少算一大半。
- 交付体量参考：单文件数百行；相互作用部分按"我的药"分组、每组"避免"与"谨慎"各占一行，涉及百余种药、数千个药名（剔除食物后）。

## 7. 版式解析坑（每条都真实污染过数据）

- **位点号正则别按样本里的最长写法写死**：`RS\d{5,}` 会漏掉 RS671（ALDH2）、RS4680（COMT）、RS1695（GSTP1）这类 3–4 位号，而它们恰是酒精代谢与阿片类那批条目。用 `RS\d{2,}`，并靠"RS 行的下一行是基因名、再下一行是基因型"来定位。
- **多栏排版里文本层顺序 ≠ 视觉顺序**：药物简介的标题就是药名本身，会紧跟在"谨慎合用"清单末尾 → 产生"吗啡·谨慎合用：吗啡"这种自指。抽完统一过滤 `item == 药名`。
- **清单续页靠页面性质判定，不靠行内容**：先判该页是否"纯名称列表"（≥12 行短行、无 `。`、无 RS），state（避免 / 谨慎）跨页延续；遇到「可以合用」「推荐合用」标题就关掉 state。不做这一步，续页药名全丢（实测华法林"谨慎合用"只抓到 14 条，实际 126 条）。
- **食物过滤不能用单字关键词**：拿"水 / 盐 / 糖 / 茶"做子串匹配，会把头孢曲松钠、苯妥英钠、秋水仙碱、氨茶碱这些真药当食物删掉。用**精确名单** + `维生素` 前缀 + `汁 / 提取物 / 饮食 / 食物` 后缀。
- **判不准就渲染看图**：列表结构、列数、合并单元格这类，用 `get_pixmap` 出图交视觉模型读一遍（问"这页有哪些小标题、各标题下完整列了哪些名"），比反复猜文本顺序快得多。
- **生成后立刻自检分布**：结论计数、字段非空率；出现"全为空"或"全是同一个值"就是赋值漏写或正则过严，当场修，别等用户发现。

## 8. 落库收尾

- 内化成**一个** `.md` 放 `1-基本信息/`（该目录默认是只读基准线，新增属本人主动要求，允许写）。
- 落库后在该目录的 `基本信息.md`「关联」行追加 `[[文件名]]`（同目录 wikilink 直接解析）：
  **只改这一行 + frontmatter `updated`**，不新开章节、不动其他内容。
- 成员自持的这类文件**不是技能规格**：结构校验按「成员自持文件」放行——不报异常、不移动、不并进基本信息正文。
- git 只 add 本次改的两个路径（新文件 + `基本信息.md`），提交信息写清来源与年份。
