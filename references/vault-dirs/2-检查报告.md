# 2-检查报告

一次检查活动 = 一个目录 `YYYY-MM-DD-机构-活动/`：

```
2026-09-11-某某市第一医院-年度体检/
├── 2026-09-11-某某市第一医院-年度体检.md   ← 汇总页
├── 报告/血常规-2026-09-11.md ← 单报告页（一项一页）
└── attachments/              ← 原图
```

- 目录名与 `4-就医记录/` 那一行同名互链。
- 同一次看病的多张单子（日期 ≤7 天）合并为一个活动：`日期` 取最早、`结束日期` 取最晚；住院取入院 / 出院日；判归属先问用户。
- 各单据自己的日期照抄不改（报告页 / 原图名 / 指标行）。
- 汇总页给人回看；单报告页供检索聚合，也是图像型 / 描述型报告（心电图、CT、超声、内镜）的唯一文字载体。

模板见技能 `templates/`；结构与列定义见技能 `references/vault-spec.md`。
