# 7-视图

给医生看的三件套，也是「面向医生的病历报告」的素材来源。全部是**派生文件**（改了上游说一声重生成）：

| 文件 | 内容 | 来源 |
|---|---|---|
| `主档案.md` | 基本信息 + 病史摘要 + 关键异常指标 + 当前用药 | `1-基本信息/` + 各记录汇总（半手工） |
| `用药记录.md` | 在吃什么、吃过什么、吃多久 | `6-用药/用药流水.md` 派生 |
| `化验指标追踪.md` | 指标分组纵向对比（带时间） | `5-指标/指标总表.csv` 派生 |

- 文件名固定这三个；视图放在各自成员目录下，跳成员引用写路径链接 `[[〈成员〉/主档案]]`。
- 成员名与 `1-基本信息/`、各表 `患者` 列保持一致。
- 报告 = 三件套 + 本次症状 + 指标时间对比 + 脱敏 → PDF。脱敏规则见 health-vault 技能「面向医生的 PDF」节。
