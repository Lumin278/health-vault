# 9-药品管理

**家里有什么药 + 什么时候过期 + 治什么**（库存视角，当保质期表用）。

| 文件 | 作用 |
|---|---|
| `药品管理表.csv` | 唯一数据源，一行一药 |
| `咨询记录.md` | 可选，默认不存在；用户说「记一下」才追加 |

- 与 `6-用药/用药流水.md` **完全独立、不联动**：开始吃药不动库存、记流水不扣库存；不做「吃了几盒 / 剩几粒」的扣减，也不主动问。库存只由用户口述驱动（「X 用完了 / 扔了」→ 改 `状态`，行不删）。
- **不留图片**：药盒 / 说明书照片只提取文字（与 `8-体重管理` 同）。

列固定 5 列：

```
药品名,适应症,到期日,状态,备注
```

- `药品名` = `通用名（剂型）`；商品名 / 别名写进 `备注`。
- `适应症` = 从说明书库照录（命令与边界见技能 `knowledge/用药/规范.md`；库 / 脚本不存在 → 只照药盒原文，不凭记忆补）；不编、不改写、不通俗化，可截短（截短处 `……`）。
- `到期日` = 照抄药盒；只印到月写 `YYYY-MM`，不推断到日。
- `状态` = 在库 / 已用完 / 已丢弃；行不删，只改这一列。
- 不记规格、数量、频次。

UTF-8 带 BOM（Excel 双击不乱码；按 `到期日` 排序 = 保质期表）。要 `.xlsx` 临时导，不手工维护两份：

```
libreoffice --headless --infilter="CSV:44,34,76,1" --convert-to xlsx --outdir 〈临时目录〉 药品管理表.csv
```

查询口径 = 只检索 + 照录：
1. 症状 / 药名检索 `适应症` 列 + 说明书库（走技能 `knowledge/用药/规范.md`）。
2. 给命中的药：药名 / 适应症原文 / 到期日 / 状态，每项带出处；已用完 / 已丢弃 / 已过期的单独标出。
3. 可另附说明书原文的禁忌 / 相互作用 / 风险等级，并把 `1-基本信息/` 的过敏史、慢病并排列出（只并排、不下结论）。
4. 禁止：排序、推荐吃哪个、剂量、疗程、病情判断；以医生 / 药师为准。
