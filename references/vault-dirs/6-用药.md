# 6-用药

`用药流水.md` —— 按「药」为主线，唯一数据源。

| 来源 | 记在哪 | 依据 |
|---|---|---|
| (a) 长期服用 / 保健品 | 顶部「当前在服」表 | `医嘱` 或 `自主` |
| (b) 看病开的药：开了什么、实际怎么吃、吃多久 | 下面「按药分节」时间线 | `医嘱` |
| (c) 自我用药：吃什么、吃多久、为什么停 | 同上，`停止原因` 必填 | `自主` |

字段：
- 药名 = `通用名（剂型）`（`布洛芬（缓释胶囊）`）。用户报商品名（优甲乐 / 芬必得）→ 查药品库 → **回问确认** → 落通用名。
- 剂量 / 规格：用户说了才记（`25mg`、`50μg`）；没说留空，不猜。
- **不记频次（一天几次）**：不问、不留空占位。
- 动作：开始 / 调量 / 续方 / 停。依据：`医嘱` / `自主`。停止原因：照用户说，不美化。来源：链 `[[就医记录总表]]` 或写「自述」。

- 就医记录总表「用药 / 治疗」列 = 本次快照 ↔ 本文件**有意交叉**，两处都写。
- `7-视图/用药记录.md` 从本文件派生，不单独维护。
- 处方原始单据放对应 `2-检查报告/〈活动〉/attachments/`。
- 边界：不判断该不该吃、要不要停、换什么药、症状是不是这药引起的 —— 只记录、只照录说明书原文。
