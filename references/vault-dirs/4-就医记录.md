# 4-就医记录

| 文件 | 内容 |
|---|---|
| `就医记录总表.md` | 全部记录，按年份分小节 —— **唯一手写源** |
| `YYYY.md` | 年子表，结构同总表，**由总表派生重生成** |

一行 = 一次医疗接触，列固定 11 列：

| 列 | 填什么 |
|---|---|
| 日期 | `YYYY-MM-DD`；住院跨天 `YYYY-MM-DD~MM-DD` |
| 机构 / 医生 | `某某市第一医院·张医生`；自查写 `—` |
| 类型 | `体检` / `就诊` / `住院` / `复查` / `自查` |
| 科室 | 无则留空 |
| 症状 / 主诉 | 当时什么不舒服、持续多久（为什么去）；自查尤其要写 |
| 判断 / 结论 | 医生诊断原话的一句话摘要；自查写 `自主判断：xxx` |
| 用药 / 治疗 | 本次开药与处置的快照；非药物处置（输液 / 打针 / 雾化 / 换药 / 理疗）也写这里 |
| 医嘱 | 医生交代的注意事项、复查要求 |
| 下次复查 | 结构化日期；没有留空 |
| 检查报告 | `[[检查活动]]` 链接；没做检查留空 |
| ID | `YYYYMMDD+序号`（如 `20260911a`），与活动页 frontmatter `就医ID` 配对 |

| 日期 | 机构 / 医生 | 类型 | 科室 | 症状 / 主诉 | 判断 / 结论 | 用药 / 治疗 | 医嘱 | 下次复查 | 检查报告 | ID |
|---|---|---|---|---|---|---|---|---|---|---|
| 2026-09-11 | 某某市第一医院·张医生 | 体检 | 体检中心 | 年度体检，无明显不适 | 甲功正常，血脂偏高 | （未开药） | 低脂饮食，3 个月后复查血脂 | 2026-12-11 | [[2026-09-11-某某市第一医院-年度体检]] | 20260911a |

- 「用药 / 治疗」列 ↔ `6-用药/用药流水.md` **有意交叉**：本列 = 本次快照（一眼看到），流水 = 这个药吃了多久、调过几次、为什么停。两处都写，只更新一处 = 待核对。
- 数值进 `5-指标/指标总表.csv`，本表不记数值；明细与原图在 `2-检查报告/〈活动〉/`。
- Markdown 表格行挂不了块 ID → 用 `ID` 列配对。
