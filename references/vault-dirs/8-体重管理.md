# 8-体重管理

`体重管理总表.csv` —— 唯一数据源，长表：一次测量 = 一组行，一行一个指标。

列固定 12 列：`日期,时间,患者,来源类型,项目,机构/设备,指标名,值,单位,参考范围,判定,笔记`

| | `5-指标/指标总表.csv` | 本表 |
|---|---|---|
| 数据来源 | 有检验报告的临床数值 | 自己在家测的（体脂秤 / 身体成分） |
| 参考范围 | 单据上印的 | App 只给定性标签 |
| 频率 | 一年几次 | 可能一天几次 |
| 归属 | 给医生看 | 自己看曲线 |

- `来源类型` = **自测**（本目录专有值，不进 `5-指标` 枚举）／体检／就诊。
- `项目` = 词表标准名（当前 `体脂秤`）；`指标名` 取词表「体重管理指标名」。
- `单位` / `参考范围`：设备印了才写，否则留空。
- `判定`：照抄 App 标签（标准 / 偏高 / 过高 / 偏低），不自己判读、不换算。
- 同一天多次称重逐条追加，不合并、不取平均；设备没给的项不写行。
- **不留原图**（只提取文字）；**不建检查活动、不加就医记录、不进 `5-指标`**。

## 画曲线（可选）

```python
import csv
rows = list(csv.DictReader(open('体重管理总表.csv', encoding='utf-8')))
for 指标 in ['体重', '体脂率', '内脏脂肪']:
    print(指标, [(r['日期'], r['值']) for r in rows if r['指标名'] == 指标])
```
